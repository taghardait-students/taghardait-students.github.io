# صفحة مكتب الطلبة الجامعيين المزابيين لقصر تغردايت بالعاصمة

## الملفات
- `data.js` ← **الملف الوحيد الذي تعدّله**: الاسم، وسائل التواصل، البرامج، الفعاليات.
- `images/` ← ضع فيه كل الصور (الشعار، صور البرامج، صور الفعاليات).
- `index.html`، `event.html`، `style.css`، `app.js` ← التصميم والمنطق، لا تلمسها.

## إضافة فعالية جديدة
1. ضع صورها في `images/` بأسماء لاتينية بدون مسافات (مثال: `rihla-2027-1.jpg`).
2. في `data.js` انسخ فعالية موجودة داخل `events` وعدّل: `id`، `title`، `date`، `place`، `summary`، `report`، `photos`.
3. ارفع التعديل إلى GitHub، وفي دقيقة يظهر على الموقع. الرابط والـQR يبقيان كما هما.

## الألوان والخطوط
مأخوذة من الشارت الغرافيكي 2026–2027: ماجنتا تغردايت، برقوقي، أخضر الواحة، كهرماني، ليلي، عاجي، مع تدرجَي «الشعلة» و«الواحة». الخطوط: Baloo Bhaijaan 2 للعناوين وTajawal للنصوص.
